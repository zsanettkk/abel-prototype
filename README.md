# ABEL: Adaptive Accessibility & Barrier Layer

A mobile companion app prototype that asks a different question about accessibility: not "Is this place accessible?" but "Is this place accessible **for you**?"

## The problem
Accessibility info is usually generic. A venue marked "step-free" can still be unusable for a particular person because of door width, a steep ramp or a broken lift.

## The idea
ABEL combines a personal accessibility profile with environmental data, so routes and venue information are matched to the individual.

## Prototype features
- Personal accessibility profile
- Accessibility-aware map
- Personalised routes
- Real-time barrier alerts
- Venue accessibility information
- Community-reported changes, clearly separated from verified information

## Prototype focus
Target user: a wheelchair user navigating unfamiliar places in London.

## Scope and honesty
- This is a design prototype with **simulated data**. It does not use live accessibility data.
- The concept includes a wearable (smart glasses). The wearable is **not built**. The app simulates the experience and interaction model.
- Designed as part of my MSc in Human-Computer Interaction at UCL for a student innovation challenge. Built with Claude (AI-assisted); I led the product concept, user focus and interaction design.
